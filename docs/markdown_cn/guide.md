# 概述

`Rapid.js` 是一个面向浏览器游戏和可视化工具的 WebGL 2D 渲染器。

你的应用负责游戏逻辑，`Rapid.js` 负责把画面画出来。

## 设计理念

Rapid 的设计目标是贴近你的 game loop。

你决定什么时候更新状态，什么时候绘制对象，以及如何组织游戏架构。`Rapid.js` 只负责接收绘制指令，并尽可能高效地完成渲染。

这让 Rapid 可以放进小型游戏、自定义引擎，或者更大的应用架构中。

## 基本帧流程

一个典型的 `Rapid.js` 渲染帧通常包含三步：

1. 清空渲染器。
2. 提交绘制指令。
3. 刷新渲染队列。

`Rapid.js` 不会替你调度帧，也不会强迫你使用某种架构。
你可以把它接入自己的循环、小游戏框架，或者更完整的引擎结构中。
